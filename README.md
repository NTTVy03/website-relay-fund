# Relay Fund Website

## Structure

- `src/` — editable website source
- `src/assets/` — images, fonts, CSS/JS assets
- `original/` — original bundled HTML backup
- `scripts/` — extract and pack scripts
- `index.html` (repo root) — final bundled single-file HTML output (generated by `npm run pack`)

## Preview

```bash
npm run preview
```

## Extract from original bundle

```bash
npm run pack
```

## Build final single HTML

```bash
npm run pack
npm run preview:build
```
